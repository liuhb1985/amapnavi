红灯辅助停车 · 判定流程

amapnavi com.carrot.amapnavi ｜ 绿色虚框为本次新增的「无电子眼兜底通道」
A · 高德 KEY_TYPE 60073 trafficLightStatus=2 红灯 / 3 绿灯 / 4 黄灯
redLightCountDownSeconds 倒计时
B · 高德 KEY_TYPE 10001 TRAFFIC_LIGHT_NUM 当前剩余灯数
routeRemainTrafficLightNum 全程剩余
C · CP 回传 UDP 7705 trafficState=1 红（CP 视觉）
xState=3 e停车（CP 已决策）
▼
◇ 总闸　navi_traffic_assist == true？
否 → 整个模块不跑（默认关）
▼ 是
◇ 道路类型　naviState.roadcate ∉ {0 快速, 1 高速}？
否（在高速/快速路）→ 不启用，红灯辅助只在国道/公路生效
▼ 是
◇ 分支① OP 视觉
xState==e2eStop
xTrafficState==traffic_red
cp_traffic_assist
▼ 是
nTrafficSpeedLimit = cp_min_speed_limit
默认 20 km/h（配合 CP 自己停车，不越权刹停）
◇ 分支② 高德导航
nTrafficCnt > 0
nTrafficLightStatus==red_light
redlight_traffic_assist
▼ 是
nTrafficSpeedLimit = red_light_min_speed_limit
默认 1 km/h（≈ 停车）
▼
置位 + 打时间戳　xTrafficRedState = true
释放条件（任一满足即 nTrafficSpeedLimit = -1）： ① 持续超过 navi_traffic_assist_time（默认 10s） ② 超过 5s 未收到 60073 广播 ③ 摄像头编号变化 / 总闸关闭
▼
注入下发 本次改造 —— 把「路口限速」写进摄像头限速通道
①
原路径：sdi_type_org == 6（闯红灯摄像头，高德 CAMERA_TYPE 2/13）且 sdi_dist >= 0
→ sdi_type=1，限速=nTrafficSpeedLimit，距离=CAMERA_DIST　标记 rl=1
②
新增兜底：red_light_no_camera 开启（默认关）且 TBT 距离 ∈ [0, red_light_max_dist]（默认 200m）
→ sdi_type=1，限速=nTrafficSpeedLimit，距离=nTBTDist　标记 rl=2
⚠ 60073 广播不带距离字段，只能借 TBT（到下一个引导动作）的距离； 加 200m 上限是为了防止「下一个 TBT 其实是更远的路口」导致提前几百米误降速。
▼
UDP → 7706 下发给 CP　→　路口限速生效（1 km/h ≈ 停）
怎么确认生效：日志里新增诊断字段 rl=来源/限速值 —— rl=1/x 走闯红灯摄像头通道，rl=2/x 走 TBT 兜底通道， rl=0/x 表示算出了限速但没发出去（本次要解决的正是这个情况）。
开启步骤：设置页 → 勾选 APP辅助停车 → 勾选 导航红灯辅助 → 如需无电子眼路口也生效，再勾选 无电子眼路口也降速。
